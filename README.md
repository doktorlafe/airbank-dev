# Air Bank Developer Portal – projekty

Portál: https://developers.airbank.cz (nejsem klient → reálně jen Public API)

| Složka | Projekt | API |
|---|---|---|
| 01-kurzy-men | Kurzy měn + porovnání s ČNB | Public |
| 02-bankomaty-pobocky | Nejbližší bankomat/pobočka | Public |
| 03-mapa | Webová mapa míst | Public |
| 04-sazka-terminaly | Sazka terminály v okolí | Public |
| 05-kurzovy-bot | Telegram bot s kurzy | Public |
| 06-sandbox-psd2 | OAuth + AISP v sandboxu (pokud existuje) | AISP/CISP |

## Další krok
1. V sekci Applications zaregistrovat aplikaci → API klíč
2. `export AIRBANK_API_KEY=...`
3. Stáhnout specifikaci Public API do `docs/`
